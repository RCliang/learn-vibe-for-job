# Ch2 幻灯片 · 演示录屏存放处

把「运行简历优化器」的录屏文件命名为：

```
resume_optimizer_demo.mp4
```

放在本目录（`slides/ch2/video/`）下即可。`slide.html` 第 19 页会自动加载并显示视频播放器（带控制条、循环播放）；文件不存在时显示占位框和命令行提示。

## 录屏建议

- **录什么**：终端里执行 `python resume_optimizer.py sample_resume.txt` 的完整过程——从敲命令到五板块报告打印完毕（可再加一次 `usage` 输出的特写）。
- **时长**：30–60 秒足够；等待 API 响应的空白时间可以剪掉或 2 倍速。
- **分辨率**：1280×720 或 16:9 任意尺寸均可，幻灯片里用 `object-fit: contain` 等比显示，不会裁切。
- **格式**：mp4（H.264）浏览器兼容性最好。
- **进阶玩法**：先跑一次 v0（去掉 `response_format`）抓一次翻车，再跑 v2 出干净报告——对比剪在一起，说服力翻倍。

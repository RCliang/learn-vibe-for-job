装好三样东西

VSCode · Python · 终端
装环境不烧脑，跟着做就行——但有一个坑，80% 的人第一天都会踩。

01 · 装环境

VSCode 与终端

① 安装 VSCode

官网 code.visualstudio.com 下载 Windows 版 → 一路下一步
扩展面板（Ctrl+Shift+X）装「中文（简体）语言包」
它本身就是简历上合格的一行字

② 打开终端

VSCode 内按 Ctrl+`——后面所有命令都在这里敲

命令作用类比
cd 目录名进入文件夹双击打开
cd ..返回上一级返回按钮
dir看里面有什么看文件列表
cls清屏擦黑板

✅ 验收：能打开 VSCode，界面是中文

01 · 装环境

安装 Python：Windows 最大的坑在第一步

  • 官网 python.org/downloads 下载 Python 3.12+ 安装包
  • 安装后重新打开终端，验证：python --version → 输出 Python 3.13.1
⚠️ 关键一步：第一屏必须勾选最下方的 Add python.exe to PATH

不勾 → 后面所有 python / pip 都报「不是内部或外部命令」。零基础第一天最常见的事故。

忘了勾？最省事的修复：重新运行安装包 → Modify → 一路下一步，它会补上 PATH。

让 Claude Code 用上 DeepSeek

编辑 C:\Users\你\.claude\settings.json（不存在就新建）：

照抄没配成功，不要反复重试，直接抄 DeepSeek 官方文档最新版

03

HTTP 与 API 基础

后面写的每一个 AI 应用，核心动作都是「发一次 HTTP 请求调用 LLM API」。
看懂它，后面所有章节的报错你都能自己读一半。

03 · HTTP 与 API

把网站想象成一家餐厅

🪑

前端

大堂和菜单——你看到的界面
网页、按钮、聊天窗口

👨‍🍳

后端

后厨——真正做菜的地方
服务器上的程序，算出结果

🤵

API

服务员——递需求、端菜回来
点单 + 上菜 = 两次数据传递

这来回的「规矩」，就是 HTTP 协议

03 · HTTP 与 API

一次 HTTP 请求长什么样必须认识的 5 个状态码——后面天天见

你 → 服务器（请求）
方法GET 查 / POST 交
URLapi.deepseek.com/chat/completions
请求头Authorization: Bearer 你的Key
请求体JSON 数据
服务器 → 你（响应）
状态码 + 响应体200 + JSON 结果
状态码在 LLM 开发中意味着
200成功，一切正常
401API Key 错了 / 没传
404URL 写错了
429请求太频繁，稍等重试
500对方的问题，重试或换模型

选做：F12 → Network 面板，亲眼看一次真实请求

💻 你（客户端）你的 Python 脚本
① 请求：POST · 请求头（带 Key）· JSON 请求体
② 响应：状态码 200 · JSON 结果
☁️ 服务器（DeepSeek）api.deepseek.com
03 · HTTP 与 API

JSON：数据的世界语

{ "name": "小明", // 键: 值（字符串双引号） "age": 18, // 数字不用引号 "skills": ["Python", "RAG"], // 数组用 [] "is_vip": true // 布尔 true/false }

语法只有三条

① 键值对，字符串用双引号
② 数字、布尔不加引号
③ 数组用方括号 []

API 传递数据几乎都用 JSON——你发的是它，收回的也是它

04

Python 三件套 + Git

教学法的分工：语法定义让 AI 写、你负责读懂；
但 import / pip / venv 是环境问题——每天都会撞见，必须自己拿手。

04 · Python 最小集

import / pip / venv

import · 拿积木

三层来源：
① 标准库（os/json）不用装
② 第三方包（openai）要先装
③ 你自己的文件要在当前目录

ModuleNotFoundError 排错两步：先问是第三方包吗？→ 装它；是自己文件吗？→ 查路径和大小写

pip · 装积木

pip install openai
pip list 看装了什么

requirements.txt = 项目购物清单，一条命令装齐
下载慢 → 加清华镜像 -i https://pypi.tuna...

venv · 独立盒子

每个项目一个独立干净的 Python 环境，互不干扰

python -m venv .venv
激活 .venv\Scripts\activate
看到 (.venv) 前缀 = 进盒了

04 · Git

Git：今天只用会 4 条命令

git init # 开新存档 git add . # 选择要存的内容 git commit -m "第一个LLM调用" # 提交存档 git push # 推送到 GitHub

首次推送：GitHub 建空仓库 → git remote add origin … → git push -u origin main

⚠️ 提交前必看

项目根目录放 .gitignore，写上 .env

GitHub 是你未来简历的项目展示地——别把 API Key 公开上去

04 · 交付物

跑通第一个 LLM API 调用ch0-hello-llm 目录：python hello_llm.py —— 全天知识，全在这 20 行代码里

# 建虚拟环境 → 按清单装依赖 → 复制 .env.example 为 .env 填 Key → 运行 python -m venv .venv .venv\Scripts\activate pip install -r requirements.txt python hello_llm.py # 模型回话 = Day 2 交付物 ✅
import拿到 OpenAI SDK→ venvSDK 装在独立环境→ pip按 requirements 安装→ POST发往 DeepSeek→ JSON 响应状态码 200→ 打印屏幕见回话

跑通后：确认 .gitignore 里有 .env → add → commit → push 到你的 GitHub

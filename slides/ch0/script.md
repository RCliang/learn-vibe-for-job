## 第 3 页 · Day 1 上午 · 分隔页

Day 1 上午，任务简单粗暴：装好三样东西——VSCode、Python，还有终端。前两样是软件，第三样……它其实一直都在你电脑里，只是你可能从没打开过。这一段没什么理解负担，跟着点就行。但有一个坑，我放到 Python 那页再讲——80% 的人第一天都会踩。

## 第 4 页 · VSCode 与终端

第一样，VSCode。程序员世界里最流行的编辑器，你可以理解为专门写代码的 Word。官网下载 Windows 版，一路下一步。装完别急着写代码，先按 Ctrl+Shift+X 打开扩展面板，把「中文（简体）语言包」装上。别笑——「给开发工具配中文环境」这件事，本身就是简历上合格的一行字，它说明你真的用过这个工具。

然后是终端。在 VSCode 里按 Ctrl 加反引号，下面弹出来的黑框就是它，以后所有命令都在这儿敲。今天先认识四个：`cd 目录名`，等于双击进入一个文件夹；`cd ..`，返回上一级；`dir`，看看文件夹里有什么；`cls`，清屏，相当于擦黑板。就这四个，够用了。

这一节的验收标准：能打开 VSCode，界面是中文。达成了的，**弹幕扣个 1**。

## 第 5 页 · 安装 Python（大坑预警）

第二样，Python。官网 python.org，下载 3.12 以上的版本。注意，装完之后要**重新打开**终端，敲 `python --version`，能蹦出版本号，才算装好。

然后就是那个坑，我必须放大了讲：安装界面第一屏，最底下有个特别不起眼的勾选框——**Add python.exe to PATH，必须勾！** 不勾会怎样？后面所有 python、pip 命令，全部报「不是内部或外部命令」。这是零基础第一天最常见的事故，没有之一。好多人到这一步，以为是自己电脑坏了，直接弃坑——其实是少勾了一个框。

已经装完才发现没勾的也别慌，不用卸载：重新运行安装包，点 Modify，一路下一步，它会自动把 PATH 补上。

Day 1 下午，好玩的来了——给你的电脑接上一个 AI 结对程序员。我们的组合是：VSCode 负责写代码，Claude Code 当结对程序员，而模型的大脑，由 DeepSeek 的 API 提供。全程国内网络直连，不需要任何海外账号。

## 第 7 页 · 为什么是这套组合

可能有同学要问：为什么不直接用网页版 AI？因为网页版是聊天，我们要的是让 AI 驻在你电脑里、跟你一起改代码的**搭档**。这类跑在终端里的 AI 编程助手不止 Claude Code 一个，Codex、DeepSeek Harness 也都行——课程里为了统一，一律拿 Claude Code 举例，你手头在用别的，完全可以接着用，不影响跟课。

为什么大脑选 DeepSeek？四个理由：手机号注册就能用，零翻墙；按量付费不用订阅，充 10 块钱够跑完整个课程；官方提供 Anthropic 兼容端点，能直接驱动 Claude Code；哪天想换智谱这些别的厂商，改两行环境变量就行，代码一行不用动。

## 第 8 页 · 开通 DeepSeek API Key

接下来去 platform.deepseek.com，手机号注册，左侧「API Keys」，创建一个。注意——Key **只显示一次**，出来马上复制存好。然后左侧「充值」，充个 10 块左右，按量扣费，用不完一直在。

这里划三条红线，请务必背下来：**Key 不发群里、不贴截图、更不能写进代码传到 GitHub。** 它就是你的密码，泄了，别人就能拿你的钱跑模型。后面我们会用 `.env` 文件专门保管它，别急。

## 第 9 页 · 安装 Claude Code

装 Claude Code 之前，先装两个前置：Node.js 18 以上的 LTS 版本，还有 Git，官网下载，都是一路下一步。然后在终端里敲这行命令：`npm install -g @anthropic-ai/claude-code`。装完重新打开终端，敲 `claude --version`，能输出版本号，就成功了。

如果你实在受不了命令行，也有备选：ZCode 桌面版，图形界面，同样能 AI 结对。不过课程主线还是按 Claude Code 讲，建议咬咬牙跟上。

装好了还不算完，得告诉 Claude Code：你的大脑，用 DeepSeek。方法是编辑屏幕上这个 settings.json 文件——不存在的请新建——把这几行抄进去，把 token 换成你自己的 Key。

## 第 11 页 · 第一次对话验证

见证时刻。建一个文件夹进去，敲一个词：`claude`，回车，它就启动了。先输 `/status` 看一眼，模型指向 DeepSeek，说明配置成功。然后随便点个菜，比如让它「写一个 Python 的 hello world，并解释每一行」。

从这一刻起，你的结对程序员正式就位。Day 1，完工，给自己鼓个掌。

## 第 12 页 · Day 2 上午 · 分隔页

Day 2 上午补理论。为什么一上来就讲 HTTP 和 API？因为后面你写的**每一个** AI 应用，剥开来看，核心动作都一样：发一次 HTTP 请求，调用大模型的 API。把这个看懂了，后面所有章节的报错，你自己就能读懂一半。

## 第 13 页 · 餐厅类比

HTTP 听着吓人，一个类比就通了。把一个网站想象成一家餐厅：**前端**，是大堂和菜单，就是你眼睛看到的界面；**后端**，是后厨，真正做菜的地方；而 **API**，是中间那个服务员——你把需求递给它，它把菜端回来。点一次单、上一趟菜，这就是两次数据传递。这来回的规矩，就叫 HTTP 协议。

以后再听到「调 API」，你就想「喊服务员」，瞬间就不神秘了。

## 第 14 页 · 请求解剖 + 状态码

再具体一点，看屏幕下方这张传信图。你发给服务器的叫**请求**：方法，GET 是查、POST 是交；URL，去哪儿，比如 DeepSeek 的这个地址；请求头里带着你的身份，Authorization 加上 Key；请求体里装 JSON 数据。服务器回给你的叫**响应**：一个状态码，加一坨结果。

状态码是重点里的重点，认识这五个就够用很久：**200**，成功，一切正常；**401**，Key 错了或者没传——以后见到它，先检查 Key；**404**，URL 写错了；**429**，你请求太猛了，歇会儿再试；**500**，对面服务器的问题，重试或者换模型。

学有余力的同学，可以按 F12 打开浏览器的 Network 面板，亲眼看一次真实的请求——看完你会对这一切更有感觉。

## 第 15 页 · JSON

请求体里装的 JSON，可以叫「数据的世界语」。语法其实就三条：第一，键值对，键和字符串要用**双引号**；第二，数字、true/false 不加引号；第三，数组用方括号括起来。就这么多。

你发给 AI 的是 JSON，AI 回给你的也是 JSON，后面每一章都在跟它打交道，先混个脸熟。

## 第 16 页 · Day 2 下午 · 分隔页

Day 2 下午，回到 Python。先把我们教学法里一个重要的分工说清楚：**语法定义这种东西，以后让 AI 写，你负责读懂就行**；但 import、pip、venv 这三样是环境问题——环境出毛病的时候，AI 也得先问你现场情况——所以它们必须你自己拿手。好消息是，三件套加起来，也就十分钟的内容。

## 第 17 页 · import / pip / venv

第一，**import，拿积木**。积木有三个来源：os、json 这种标准库，Python 自带，不用装；openai 这种第三方包，要先装才能拿；还有你自己写的文件，得在当前目录、名字和大小写都对得上。

以后你一定会撞见 ModuleNotFoundError，翻译过来是「找不到积木」。排错就两步：先问，它是第三方包吗？是，就去装它；是自己文件吗？查路径、查大小写。

第二，**pip，装积木**。`pip install 包名` 安装，`pip list` 看装了啥。项目一般配一个 requirements.txt，相当于购物清单，一条命令把所有依赖装齐。国内下载慢，加一个清华镜像源。

第三，**venv，独立盒子**。每个项目一个独立干净的 Python 环境，互不干扰——不然 A 项目要新版库、B 项目要旧版库，直接打起来。建盒子、激活盒子，看到命令行前面多了个 `(.venv)` 前缀，就说明你在盒子里了。

## 第 18 页 · Git

然后是 Git，版本管理，你就理解成**游戏存档**。今天只用会四条：`git init`，开个新存档；`git add .`，选择要存的内容；`git commit`，提交存档；`git push`，把存档推上 GitHub。首次推送多两步，屏幕上有，照着敲就行。

但右下角这个警告，请读三遍：提交之前，确认项目根目录有 `.gitignore` 文件，里面写上 `.env`。还记得第 8 页的三条红线吗？GitHub 是你以后简历的项目展示地，别把 API Key 公开挂上去——真发生了，赶紧去 DeepSeek 后台把 Key 作废重建。

## 第 19 页 · 交付物

万事俱备，来收这两天的大果实。课程配套的 ch0-hello-llm 目录里，就一个文件：hello_llm.py，20 行代码。别小看这 20 行——这两天学的所有东西都在里面了：import 拿 SDK，venv 给它独立环境，pip 按清单装依赖，POST 发往 DeepSeek，收回 JSON，状态码 200，打印——屏幕上，模型回你话。

操作顺序：建虚拟环境、激活、装依赖、把 .env.example 复制成 .env 填上你的 Key，然后 `python hello_llm.py`。回车那一刻——欢迎来到 AI 应用开发的世界。

跑通之后，add、commit、push，推上你自己的 GitHub。

## 第 20 页 · 通关自测 + 预告（结尾 CTA）

最后，进入下一章之前，用这六条给自己做个体检：`python --version` 能出版本号；claude 能对话，`/status` 显示 DeepSeek；200、401、404、429 能脱口而出是什么意思；能**独立**完成建 venv、激活、装包这套动作；ModuleNotFoundError 两步排错法能说上来；hello_llm.py 跑通并推上了 GitHub——而且 `.env` 没被推上去。

## 第 3 页 · Day 1 上午 · 分隔页

Day 1 上午，任务简单粗暴：装好三样东西，VSCode、Python，还有终端。前两个是软件，第三个其实一直都装在你电脑里，只是你可能从来没点开过它。这段没什么理解门槛，跟着点鼠标就行。不过有一个坑我留到Python那页专门讲，八成的人第一天都栽在那儿。

## 第 4 页 · VSCode 与终端

第一样，VSCode。程序员圈子里最流行的编辑器，你可以把它理解成专门写代码用的Word。去官网下载Windows版，一路下一步就行。装完先别急着写代码，按 Ctrl+Shift+X 打开扩展面板，把「中文（简体）语言包」装上。别笑，「给开发工具配好中文环境」这件小事，写在简历上就是合格的一行——它说明你真用过这个工具，不是临时抱佛脚。

然后是终端。VSCode 里按 Ctrl 加反引号，弹出来的那个黑框框就是它，以后所有命令都在这儿敲。今天先认脸熟四个：`cd 目录名`，相当于双击进一个文件夹；`cd ..`，退回上一级；`dir`，看看这文件夹里有啥；`cls`，清屏，跟擦黑板一个意思。够用了，先记这四个。

这一节怎么算过关？打开VSCode，界面是中文的。做到的，**弹幕扣个 1**。

## 第 5 页 · 安装 Python（大坑预警）

第二样，Python。官网 python.org，下载 3.12 以上的版本。注意，装完之后要**重新开一个终端**，敲 `python --version`，能蹦出版本号才算装好，别用装之前那个旧窗口。

然后就是那个坑，我必须放大讲：安装界面第一屏，最下面有个特别不起眼的勾选框——**Add python.exe to PATH，这个框必须勾上！** 不勾会怎样？后面所有 python、pip 命令统统报错，「不是内部或外部命令」。这是零基础第一天最容易翻车的地方，没有之一。很多人走到这一步，还以为是自己电脑坏了，直接弃坑——其实就是少勾了一个框而已。

已经装完才发现没勾的，也别慌，不用卸载重装：重新运行一遍安装包，点 Modify，一路下一步，它会自动把 PATH 补上。

## 第 7 页 · 为什么是这套组合

可能有同学要问，干嘛不直接用网页版AI聊天？因为网页版是聊天，我们要的是让AI住进你电脑里、跟你一起改代码的**搭档**。这类跑在终端里的AI编程助手不止 Claude Code 一个，Codex、DeepSeek Harness 都行，课程里为了统一口径，一律拿 Claude Code 举例。你手头已经在用别的也没关系，接着用就行，不影响跟课。

那大脑为什么选 DeepSeek？说几个实在的理由：手机号就能注册，零翻墙；按量付费不用订阅，充个十块钱够你跑完整个课程；官方提供 Anthropic 兼容端点，能直接拿来驱动 Claude Code；哪天你想换成智谱或者别的厂商，改两行环境变量就行，代码一行都不用动。

## 第 8 页 · 开通 DeepSeek API Key

接下来去 platform.deepseek.com，手机号注册，左边「API Keys」，点创建。注意，这个 Key **只显示一次**，出来了马上复制存好，别手滑关掉页面。然后左边「充值」，充个十块钱左右，按量扣费，用不完一直留着。

这里划三条红线，务必刻在脑子里：**Key 不发群里、不贴截图、更不能写进代码传到 GitHub 上。** 它就是你的密码，泄露出去，别人就能拿你的钱跑模型。后面我们会用 `.env` 文件专门保管它，先记住这三条，别急。

## 第 9 页 · 安装 Claude Code

## 第 12 页 · Day 2 上午 · 分隔页

Day 2 上午补点理论。为什么一上来就讲 HTTP 和 API？因为往后你写的**每一个**AI应用，扒开来看，核心动作都一样：发一次 HTTP 请求，调用大模型的 API。这个看懂了，后面章节冒出来的报错，你自己就能读懂一半。

## 第 13 页 · 餐厅类比

HTTP 听着吓人，一个类比就通了。把一个网站想象成一家餐厅：**前端**是大堂和菜单，也就是你眼睛看到的界面；**后端**是后厨，真正做菜的地方；中间那个来回跑的服务员，就是 **API**——你把需求递给它，它把菜给你端回来。点一次单、上一趟菜，这就是两次数据传递，来回的这套规矩，就叫 HTTP 协议。

以后再听到「调 API」，你就想「喊服务员」，瞬间没那么玄乎了。

## 第 14 页 · 请求解剖 + 状态码

再具体点，看屏幕下方这张传信图。你发给服务器的叫**请求**：方法，GET 是查、POST 是交；URL，去哪儿，比如 DeepSeek 的这个地址；请求头里带着你的身份，Authorization 加上 Key；请求体里装着 JSON 数据。服务器回给你的叫**响应**：一个状态码，加一坨结果。

状态码是重点中的重点，记住这五个能顶用很久：**200**，成功，一切正常；**401**，Key 错了或者压根没传，以后见到它先去查 Key；**404**，URL 写错了；**429**，你请求太猛了，歇会儿再试；**500**，对面服务器自己的问题，重试或者换个模型。

学有余力的同学可以按 F12 打开浏览器的 Network 面板，亲眼看一次真实的请求跑一遍，看完你会对这套东西更有感觉。

## 第 15 页 · JSON

请求体里装的 JSON，可以叫「数据的世界语」。语法其实就三条：第一，键值对，键和字符串要用**双引号**；第二，数字、true/false 不加引号；第三，数组用方括号括起来。就这么多，不复杂。

你发给AI的是 JSON，AI 回你的也是 JSON，后面每一章都要跟它打交道，先混个脸熟就行。

## 第 16 页 · Day 2 下午 · 分隔页

Day 2 下午，回到 Python。先把我们这门课一个重要的分工说清楚：**语法这种细节，以后尽管交给AI写，你负责读懂就行**；但 import、pip、venv 这三样是环境问题——环境一出毛病，AI 也得先问你现场情况，所以这三样必须你自己拿得下来。别担心，三件套加起来，撑死十分钟内容。

## 第 17 页 · import / pip / venv

先说 **import，拿积木**。积木有三个来源：os、json 这种标准库，Python 自带，不用装；openai 这种第三方包，得先装了才能拿；还有你自己写的文件，得保证在当前目录、名字和大小写都对得上号。

以后你迟早会撞见 ModuleNotFoundError，翻译过来就是「找不到积木」。排错就两步：先问自己，它是第三方包吗？是，就去装；是自己的文件吗？那就查路径、查大小写。

再说 **pip，装积木**。`pip install 包名` 装，`pip list` 看看都装了啥。项目一般会配一个 requirements.txt，相当于购物清单，一条命令把所有依赖一次装齐。国内下载慢，记得加个清华镜像源。

最后是 **venv，独立盒子**。每个项目一个干净独立的 Python 环境，互不干扰，不然 A 项目要新版库、B 项目要旧版库，俩人能打起来。建盒子、激活盒子，看到命令行前面多了个 `(.venv)`，就说明你人在盒子里了。

## 第 18 页 · Git

然后是 Git，版本管理，你可以理解成**游戏存档**。今天先学会四条：`git init`，开一个新存档；`git add .`，选好要存的内容；`git commit`，提交存档；`git push`，把存档推上 GitHub。首次推送多两步，屏幕上都有，照着敲就行。

不过右下角这条警告，麻烦多读两遍：提交之前，先确认项目根目录有 `.gitignore` 文件，里面写上 `.env`。还记得第 8 页那三条红线吗？GitHub 以后是你简历上的项目展示地，千万别把 API Key 公开挂上去。真手滑传上去了，赶紧去 DeepSeek 后台把 Key 作废重建，别犹豫。

## 第 19 页 · 交付物

万事俱备，来收这两天的大成果。课程配套的 ch0-hello-llm 目录里，就一个文件，hello_llm.py，20 行代码。别小看这 20 行，这两天学的东西全在里面了：import 拿 SDK，venv 给它一个独立环境，pip 照清单装依赖，POST 发往 DeepSeek，收回 JSON，状态码 200，打印出来——屏幕上，模型开口回你话了。

操作顺序：建虚拟环境、激活、装依赖，把 .env.example 复制成 .env 填上你自己的 Key，然后敲 `python hello_llm.py`。回车那一下，欢迎来到 AI 应用开发的世界。

跑通之后别忘了，add、commit、push，推上你自己的 GitHub。

最后，进下一章之前，用这六条给自己做个体检：`python --version` 能蹦出版本号；claude 能正常对话，`/status` 显示 DeepSeek；200、401、404、429 你能脱口而出是什么意思；能不看教程独立完成建 venv、激活、装包这一套；ModuleNotFoundError 的两步排错法说得上来；hello_llm.py 跑通并推上了 GitHub——而且 `.env` 没被一起推上去。
